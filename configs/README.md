# Configuration files

- `b2_cases.txt`: cases for the Table 4 finite-time threshold comparison driver.
- `threshold_list.txt`: parameter factors for the Supplementary Figure S1 empirical threshold scan.
- `list.txt`: dose-response runs for Supplementary Figures S2 and S3.

These files are examples matching the manuscript settings. You may adjust dose ranges or grid resolution before rerunning the full simulations.
